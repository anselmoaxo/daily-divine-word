# Liturgia Diária – Anselmo Tech

Aplicação web moderna e responsiva para acompanhamento da Liturgia Diária da Igreja Católica Apostólica Romana, com opção de cadastro para recebimento diário via WhatsApp integrado ao n8n.

## Tecnologias Utilizadas
- React 18 com Vite e TypeScript
- Tailwind CSS para estilização litúrgica
- Framer Motion para transições suaves
- Integração direta com Webhook do n8n para cadastro de usuários
